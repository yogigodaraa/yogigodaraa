# Hi, I'm Yogender Godara 👋

AI developer and cybersecurity & network engineer in Perth, Australia. CCNP-certified, 4× hackathon winner.

I build end-to-end systems that turn messy inputs (chat exports, industrial sensor feeds,
raw logs, procedural PDFs) into clear, actionable answers. Most of my AI apps are
**bring-your-own-key (BYOK)**, so cost and privacy stay with the user.

**Currently learning:** multi-agent orchestration with LangGraph, production ML for
security operations, and writing software that's tested, documented and easy to hand over.
